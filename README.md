# COSMOS X

Windows JUCE VST3 instrument for Cubase 15. Version 0.1 foundation: 16-voice MIDI synth, saw/square/sine oscillator, master level, low-pass tone control and ADSR. This is an initial build, not the complete planned product: wavetable synthesis, FM/unison, modulation matrix, tempo-synced arpeggiator, effects rack and expanded presets remain future work.

Open **Actions** to view the Windows build. Download the `COSMOS_X_COMPLETE` ZIP artifact after a successful run. Run `COSMOS_X_Installer.exe`; it installs to `C:\\Program Files\\Common Files\\VST3\\COSMOS X.vst3`. Restart Cubase and rescan plug-ins.

JUCE 8.0.6 is fetched from the official JUCE repository at build time. Review JUCE licensing before commercial distribution.
