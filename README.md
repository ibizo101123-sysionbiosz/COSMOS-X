# ASTORIAS

Windows JUCE VST3 instrument for Cubase 15. Version 0.1 foundation: 16-voice MIDI synth, saw/square/sine oscillator, master level, low-pass tone control and ADSR. This is the existing COSMOS X instrument with its product name and installer branding changed to ASTORIAS; its sound engine and controls are otherwise unchanged.

Open **Actions** to view the Windows build. Download the `ASTORIAS_COMPLETE` ZIP artifact after a successful run. Run `ASTORIAS_Installer.exe`; it installs to `C:\\Program Files\\Common Files\\VST3\\ASTORIAS.vst3`. Restart Cubase and rescan plug-ins.

JUCE 8.0.6 is fetched from the official JUCE repository at build time. Review JUCE licensing before commercial distribution.
