# ASTORIAS

ASTORIAS is a Windows VST3 polyphonic synthesizer for Cubase and other compatible hosts.

Current feature set:
- 32-voice polyphony
- Two detunable oscillators plus a sub oscillator
- Saw, square, sine and triangle waveforms
- Low-pass, high-pass and band-pass filter modes
- Resonance, LFO modulation, drive and ADSR controls
- 300 selectable categorized synth patches in the preset browser
- 10 sound categories: Psy Bass, Rolling Bass, Sub Bass, Trance Lead, Psy Lead, Supersaw, Pluck, Pads, Arps and FX-style synth tones
- Previous/next arrow buttons for fast preset browsing, with wraparound navigation
- Futuristic dark space interface with cyan/violet accents and redesigned control panels

The 300 patches are generated synth parameter variations, not sampled Nexus libraries. The FX category contains effect-like synth tones; this build does not yet include dedicated delay/reverb effects, wavetable import, a full modulation matrix, or a true step arpeggiator. Preset variety should be auditioned in the plugin and refined based on listening tests.

Open **Actions** and wait for the latest **ASTORIAS Windows Build** run to finish successfully. Download the `ASTORIAS_COMPLETE` artifact, extract the ZIP, then run `ASTORIAS_Installer.exe`. Restart Cubase and rescan plug-ins.

JUCE 8.0.6 is fetched from the official JUCE repository at build time. Review JUCE licensing before commercial distribution.
